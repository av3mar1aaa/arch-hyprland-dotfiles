# Arch Linux + Hyprland dotfiles

Current personal Arch Linux / Hyprland desktop configuration.

Main components:

- Hyprland
- Quickshell
- Matugen
- Kitty / Ghostty
- Rofi
- Fastfetch
- Nautilus + Papirus Dark
- eDEX-UI theme

Custom shell features include:

- `SUPER + ESC` — Control Center
- `SUPER + K` — live Hyprland shortcut viewer
- `SUPER + O` — floating/pinned spotlight window
- `SUPER + S` — Kitty scratchpad

Secrets and machine-specific credentials are intentionally excluded from
this public repository. A complete encrypted disaster-recovery snapshot
is stored separately in a private repository.
